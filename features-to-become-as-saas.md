Features required to become "SaaS"

Customer/Subscription management and automated onboarding:
- Allow someone to start a subscription to the service
- Automatically create a new organisation for this user, make them the owner + admin
- automated creation a separate DB schema per organisation
- automatically manage switching schemas depending on user context i.e. they belong to organisation X instead of organisation Y
